# RuotaDellaFortuna
## progetto personale inspirato al omonimo programma televisivo 
# Elementi principali:
  1. jagged array contenente la frase, gia inizializzato - parole rappresentate da caratteri per il controllo
  2. controllo sull'input del utente per verificare l'inserimento della lettera corretta/errata
  3. una specie di "ruota" contente i punti da poter guadagnare durante il turno
     3.1 bonus all'interno della ruota e gestione delle probabilita'
  4. RIVALUTAZIONE PUNTO 4
  5. sistema di gestione dei crediti e negozio delle vocali
## POSSIBILI IMPLEMENTAZIONI A PROGETTO GIA COMPLETATO
  - possibilita' di fare partecipare 3 utenti insieme con conti separati per ciascuno
  - possibilita' di fare inserire una frase bonus da fare indovinare agli altri
  - frasi genereti dall'ia tramite un api, senza probabilita' di ripetizioni nel caso di averci gia' giocato numerose volte
  - PUNTO RIVALUTATO: stampa a video di una tastiera contente le lettere dell'alfabeto, colorando del colore opportuno quelle azzeccate/errate
